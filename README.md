# Jemi Game Arcade

A Three.js arcade of three playable games set in a Lagos night market: Identity Dash, Avatar Jump, and Salubata. Every player brings their own start.ng character into all three.

## Run locally

```sh
npm install
npm run dev
```

```sh
npm run build     # production bundle in dist/, plus cover.png and startng.json
npm run preview   # serve the built bundle
npm run cover     # regenerate cover.png
npm run check     # JavaScript syntax check
```

## Publishing to start.ng

The built `dist/` folder is committed on purpose: start.ng serves static files and never runs a build. `npm run build` also copies `cover.png` and `startng.json` into `dist/`.

- `cover.png` — 16:10 card image, generated by `scripts/make-cover.mjs` (needs `sharp`: `npm i sharp --no-save`).
- `startng.json` — leaderboard columns: `score`, `stars`, `coins` (all highest-wins).

Check before publishing:

```sh
curl -X POST https://api.start.ng/games/check \
  -H "Content-Type: application/json" \
  -d '{"repo_url":"https://github.com/Olnuel/jemi-game-arcade"}'
```

Then publish once and open the returned `approve_url`. After that, every push to the published branch updates the game automatically.

## Current scope

- **Identity Dash** is an endless three-lane runner with moving obstacles, jumpable barriers, coins, lives, pause/resume, restart, score, and a saved local personal best.
- **Avatar Jump** is a seven-platform vertical climb with steering, jump physics, one-way platform collision (you can land back on your current platform), platform edge falling, collectible stars, a rooftop finish, fall failure, pause, and restart.
- **Salubata** is single player. Hold Down or S and release to throw the slipper behind you and set the throwing mark, walk to the mark, aim left/right, then hold Up or Space and release to slide the slipper through the rubber bands. You get **4 turns** to clear all **9 bands**; clearing them all wins, running out of turns loses. It keeps the animated walk-to-mark phase.
- All three games share one Three.js player-character builder and accept the same body, skin, outfit, hair, hat and accessory style fields.
- On a `*.start.ng` address the adapter asks `https://start.ng/connect` for `{ id, name, style }` over a source- and origin-checked `postMessage` handshake, falling back to the start.ng `guest` look for signed-out visitors. It never reads or stores start.ng credentials or email.
- Finished runs are sent to the start.ng leaderboard with `startng:score`, and the top runs are shown on the menu. Only signed-in players can save; guests play normally.
- Not implemented: computer opponents, online multiplayer rooms, unlocks, mobile flick/spin physics.

## Controls

- **Identity Dash:** Left/right arrows or A/D to change lanes; Space, Up or W to jump; Escape pauses and resumes; R or the result button restarts; touch buttons and swipe work on touch screens.
- **Avatar Jump:** Left/right arrows or A/D to steer; Space, Up or W to jump; Escape pauses and resumes; R or the result button restarts after a finish or fall; touch buttons and swipe work on touch screens.
- **Salubata:** Hold Down or S, then release, to throw the slipper behind you. After the walk to the mark, aim with left/right, then hold Up or Space and release to slide. Escape pauses and resumes; R or the result button starts a new round. On mobile, hold the THROW button to charge.

## Look

The palette is a warm Lagos night market: danfo yellow `#ffcc00`, ember `#ff5722`, Nigerian green `#00a05a` and gold `#ffd23f` on a near-black ground `#0b0608`, with cream `#fff3dc` type. Lighting is warm rather than the old cool teal wash. Tokens live at the top of `src/style.css`.

## Verification

- `npm run check` validates JavaScript syntax only. **It is not a unit-test suite, and there is still no automated test or CI in this repo.**
- `npm run build` produces the static bundle in `dist/`.
- Verified in a local browser after the redesign: all three games launch from the shelf, the HUD reports the right labels (`LEVEL 1/7` for Avatar Jump, `TURN 1/4` and `0/9 BANDS` for single-player Salubata), and the production build serves correctly from `dist/`.
- Still unverified: the start.ng hosted identity handshake, centrally managed style delivery, and leaderboard round-trips. These only work once the game is live at a real `*.start.ng` address.
